Fundamentação Histórica • 1970 vs 1990

🏛️ 1. O Abismo entre Dois Mundos (O Impedance Mismatch)

No início da computação corporativa, Edgar F. Codd (IBM, 1970) formalizou o Modelo Relacional. O banco de dados pensa exclusivamente em tabelas bidimensionais, tuplas de dados primitivos escalares e integridade relacional via chaves primárias (PK).

Já a Orientação a Objetos de Alan Kay pensa em entidades vivas na memória RAM: encapsulamento, comportamentos (métodos), herança polimórfica e ponteiros de referência (identidade de Heap via obj1 == obj2). Ted Neward denominou essa barreira de "O Vietnã da Computação".

🎭 Metáfora Lúdica do Tradutor Juramentado:
A classe de negócio em Java é um diplomata que só fala português culto (regras de validação). O banco de dados é um diplomata que só fala dialeto SQL antigo. O Padrão DAO é o tradutor juramentado no meio da mesa: ele recebe comandos do Java e gera SQL seguro; quando o banco entrega uma pasta com fichas soltas (ResultSet), o DAO hidrata e monta o objeto Java na memória.

🚫 2. O Pecado Original: Misturar Regra de Negócio com SQL

Em 2001, a Sun Microsystems publicou o catálogo Core J2EE Patterns. O erro mais amador de um programador é colocar comandos JDBC (Connection, PreparedStatement) dentro das entidades de domínio ou nos botões de telas Swing.

Se você coloca um INSERT dentro de Produto.java, a classe ganha duas razões para mudar (violando o SRP - Single Responsibility Principle): muda se as regras financeiras mudarem e muda se a empresa trocar o SQLite pelo PostgreSQL!

🎮 Metáfora do Controle Remoto Universal (Interfaces):
A Interface DAO funciona exatamente como o controle remoto da sua sala: tem botões bem definidos como salvar(Cliente) e buscarPorId(Long). O seu Controller aperta esses botões sem precisar saber se a TV é Samsung, LG ou Philips (SQLite, PostgreSQL ou Mock em memória).

5. Implementação Canônica com JDBC: LivroDAOSqlite.java

Implementação concreta utilizando PreparedStatement, try-with-resources e o método canônico de mapeamento mapearLinha(ResultSet):


package br.com.bookstore.dao;import br.com.bookstore.factory.ConexaoFactory;
import br.com.bookstore.model.Livro;
import java.sql.Connection;
import java.sql.PreparedStatement;
import java.sql.ResultSet;
import java.sql.SQLException;
import java.sql.Statement;
import java.util.ArrayList;
import java.util.List;
import java.util.Optional;public class LivroDAOSqlite implements LivroDAO {    public LivroDAOSqlite() {
        criarTabelaSeNaoExistir();
    }    private void criarTabelaSeNaoExistir() {
        String sql = "CREATE TABLE IF NOT EXISTS livros (" +
                     "id INTEGER PRIMARY KEY AUTOINCREMENT, " +
                     "titulo TEXT NOT NULL, " +
                     "autor TEXT NOT NULL, " +
                     "preco REAL NOT NULL);";
        try (Connection conn = ConexaoFactory.obterConexao();
             Statement stmt = conn.createStatement()) {
            stmt.execute(sql);
        } catch (SQLException e) {
            throw new RuntimeException("Falha ao inicializar tabela 'livros' no SQLite: " + e.getMessage(), e);
        }
    }    private Livro mapearLinha(ResultSet rs) throws SQLException {
        Long id = rs.getLong("id");
        String titulo = rs.getString("titulo");
        String autor = rs.getString("autor");
        double preco = rs.getDouble("preco");
        return new Livro(id, titulo, autor, preco);
    }    @Override
    public void salvar(Livro livro) {
        String sql = "INSERT INTO livros (titulo, autor, preco) VALUES (?, ?, ?);";
        try (Connection conn = ConexaoFactory.obterConexao();
             PreparedStatement stmt = conn.prepareStatement(sql, Statement.RETURN_GENERATED_KEYS)) {
            
            stmt.setString(1, livro.getTitulo());
            stmt.setString(2, livro.getAutor());
            stmt.setDouble(3, livro.getPreco());
            stmt.executeUpdate();            try (ResultSet chaves = stmt.getGeneratedKeys()) {
                if (chaves.next()) {
                    livro.setId(chaves.getLong(1));
                }
            }
        } catch (SQLException e) {
            throw new RuntimeException("Erro ao salvar livro: " + e.getMessage(), e);
        }
    }    @Override
    public Optional<Livro> buscarPorId(Long id) {
        String sql = "SELECT id, titulo, autor, preco FROM livros WHERE id = ?;";
        try (Connection conn = ConexaoFactory.obterConexao();
             PreparedStatement stmt = conn.prepareStatement(sql)) {
            
            stmt.setLong(1, id);
            try (ResultSet rs = stmt.executeQuery()) {
                if (rs.next()) {
                    return Optional.of(mapearLinha(rs));
                }
                return Optional.empty();
            }
        } catch (SQLException e) {
            throw new RuntimeException("Erro ao buscar livro por ID: " + e.getMessage(), e);
        }
    }
    @Override
    public List<Livro> listarTodos() {
        String sql = "SELECT id, titulo, autor, preco FROM livros ORDER BY titulo;";
        List<Livro> lista = new ArrayList<>();
        try (Connection conn = ConexaoFactory.obterConexao();
             PreparedStatement stmt = conn.prepareStatement(sql);
             ResultSet rs = stmt.executeQuery()) {
            
            while (rs.next()) {
                lista.add(mapearLinha(rs));
            }
        } catch (SQLException e) {
            throw new RuntimeException("Erro ao listar livros: " + e.getMessage(), e);
        }
        return lista;
    }
}
